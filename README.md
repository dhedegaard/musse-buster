# Musse Buster!

A browser-based bubble-buster game — click groups of 3+ same-colored bubbles to remove them before they stack to the top.

## Requirements

- Node 24
- npm 11

## Commands

```bash
npm ci          # Install dependencies
npm run dev     # Dev server with Turbopack
npm run lint    # ESLint
```

## Controls

| Key | Action |
|-----|--------|
| Click bubble | Remove group (≥3 same color) |
| `p` / Space | Pause / resume |
| `n` | New game |
